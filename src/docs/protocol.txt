Клиент и сервер общаются с помощью WebSocket в виде json сообщений вида:

{
    type: "...",
    [имя поля 1]: "...",
    [имя поля 2]: "...",
    ...
}

Допустимые типы сообщений:

    - create
        - клиент: отправляет серверу сообщение, что он создаёт игру и запрашивает invite-код
        - сервер: присылает подтверждение присоеиняющемуся игроку, что он успешно присоединился к игре

    - invite
        - клиент: отправляет серверу сообщение, что он присоединяется к игре с invite-кодом в соответствующем поле
        - сервер: отправляет сообщение, создающему игру, с его invite-кодом, который он может передать присоединяющемуся

    - gameState
        - клиент: отправляет серверу сообщение о готовности начать сражение, а также свою расстановку кораблей
        - сервер: принимает расстановку кораблей игрока, отправляет клиенту сообщение о том, ходит ли он первым

    - shot
        - клиент: отправляет серверу куда он стреляет
        - сервер: принимает сообщение о выстреле и перенаправляет его противнику

    - shot-result
        - клиент: отправляет серверу результат выстрела соперника (т.е. попадание/промах/убил)
        - сервер: принимает сообщение о результате выстрела и перенаправляет его противнику

    - gameResult
        - клиент: принимает сообщение от сервера о победе/проигрыше, а так же получается расстановку кораблей противника в виде List<ShipModel>
        - сервер: отправляет сообщение клиентам от их победе/проигрыше, а так же расстановку кораблей противника, инициирует завершение сессии web socket

Формат сообщений:

    - create:
        - client:
            {
                "type": "create"
            }
        - server:
            {
                "type": "create",
                "status": "ok"    //error
            }

    - invite:
        - client:
            {
                "type": "invite",
                "code": "AB2CD"
            }
        - server:
            {
                "type": "invite",
                "code": "AB2CD"
            }

    - gameState:
        - client:
            {
              "type": "gameState",
              "ships": [
                {
                  "size": 4,
                  "horisontal": true,
                  "position": {
                    "x": 1,
                    "y": 3
                  }
                },
                {
                  "size": 3,
                  "horisontal": false,
                  "position": {
                    "x": 5,
                    "y": 7
                  }
                },
                {
                  "size": 2,
                  "horisontal": true,
                  "position": {
                    "x": 9,
                    "y": 0
                  }
                }
              ]
            }
        - server:
            {
                "type": "gameState",
                "turn": "you"  //enemy
            }
    - shot:
        - client:
            {
                "type": "shot",
                "col": 5,
                "row": 3
            }
        - server:
            {
                "type": "shot",
                "col": 5,
                "row": 3
            }

    - shot-result:
        - client:
            {
                "type": "shot-result",
                "result": "miss" // "hit", "kill"
            }
        - server:  // на этом этапе сервер ведёт учёт подбитых кораблей
            {
                "type": "shot-result",
                "result": "miss" // "hit", "kill"
            }

    - gameResult:
        - server:
            {
                "type": "gameResult",
                "state": "win" // lose
                "ships": [
                    {
                      "size": 4,
                      "horisontal": true,
                      "position": {
                        "x": 1,
                        "y": 3
                      }
                    },
                    {
                      "size": 3,
                      "horisontal": false,
                      "position": {
                        "x": 5,
                        "y": 7
                      }
                    },
                    {
                      "size": 2,
                      "horisontal": true,
                      "position": {
                        "x": 9,
                        "y": 0
                      }
                    }
                  ]
            }



Во время игры сервер считает подбитые корабли противников и завершает игру, когда все корабли одного из игроков подбиты
    ! Сервер не занимается сохранением данных, только роль "судьи" между игроками для данной партии.
    Все игроки остаются анонимными, статистика игр не ведётся.
